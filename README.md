# Planet Pearl

Slow living, knitting & quilting. Static site, no build step.

- `site/` the website (open `site/index.html`, or run `node serve.js` and visit http://localhost:5173)
- `site/js/config.js` links, contact email and discount code live here
- `site/js/videos.js` the channel's films (id, title, length, date)
- `blender/yarn_film.py` renders the hero yarn film (see the header of the script for the command)
- `site/assets/hero/` the rendered film frames

The live site is the `gh-pages` branch, which is just the contents of `site/`.
